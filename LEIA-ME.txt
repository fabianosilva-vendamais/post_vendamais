VERSÃO ESTÁTICA (sem build). Como publicar:
1. No GitHub, repositório post_vendamais: apague TODOS os arquivos e pastas antigos (Settings > Delete não; apenas apague os arquivos, ou crie um repositório novo chamado post-vendamais-site).
   Forma simples: Add file > Upload files, arraste todo o conteúdo desta pasta e confirme. Depois apague pelo site as pastas app/, supabase/, scripts/ e os arquivos package.json, next.config.mjs (lápis > ícone de lixeira).
2. Edite config.js no GitHub: cole Project URL e anon key do Supabase.
3. Na Vercel, projeto post-vendamais > Settings > General > Framework Preset = "Other", Build Command vazio, Output Directory vazio. Salve. Deployments > Redeploy.
4. Abra https://post-vendamais.vercel.app/ com Ctrl+F5.
A IA de texto e imagem usa as Edge Functions do Supabase (rode setup-supabase.sh uma vez, ou eu te guio).
