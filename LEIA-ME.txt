COMO SUBIR NO GITHUB (substituindo tudo)
1. Abra github.com/fabianosilva-vendamais/post_vendamais
2. Para cada pasta/arquivo antigo que você queira limpar, pode deixar; os novos sobrescrevem os de mesmo nome.
3. Clique em "Add file" > "Upload files".
4. Arraste TODO o conteúdo desta pasta (os arquivos e as pastas app, engine, assets, supabase) para a área de upload.
5. Em "Commit changes", deixe "Commit directly to the main branch" e confirme.
6. A Vercel faz o deploy sozinha em ~2 min. Abra https://post-vendamais.vercel.app/app/ com Ctrl+F5.

Opcional: renomeie gitignore.txt para .gitignore e env.example.txt para .env.example (não é necessário para funcionar).
Apague do repositório, se quiser: scripts/, github/, COMO-USAR.txt, PUSH.md, uploads/, screenshots/ (não fazem falta).
