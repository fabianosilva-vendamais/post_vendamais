# Primeiro push para github.com/fabianosilva-vendamais/post_vendamais

Baixe o ZIP do projeto, descompacte e rode na pasta (Git instalado):

```bash
git init
git add .
git commit -m "VendaMais Content Engine v1"
git branch -M main
git remote add origin https://github.com/fabianosilva-vendamais/post_vendamais.git
git push -u origin main
```

Sem terminal: GitHub Desktop → File → Add local repository (a pasta) → Publish repository → escolher `post_vendamais`.

Depois do push, me avise: eu leio o repositório, confiro a estrutura e sigo com a Vercel (posso criar o projeto Vercel ligado a este repo, você só cola as variáveis de ambiente).
